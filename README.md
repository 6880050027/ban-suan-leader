# เส้นทางผู้บริหาร: เมืองบ้านสวน

เกมเตรียมความพร้อมผู้บริหารสถานศึกษามัธยมศึกษาไทย 30 ด่าน (6 ช่วง) ผู้เล่นรับบทผู้อำนวยการ "โรงเรียนบ้านสวนวิทยา" ในเมือง 3 มิติที่หมุน ซูม และเลื่อนดูได้ แตะตัวละครเพื่อดูสิ่งที่เขาทำไปแล้ว และเลือกวิธีทำงานกับเขาได้ 5 แบบ ได้แก่ สั่งการ สอนงาน สนับสนุน มอบหมาย และปรึกษาหารือ เนื้อหาครอบคลุมงาน 4 ด้านตามกฎกระทรวงกระจายอำนาจฯ พ.ศ. 2550 วนสลับกันทุกช่วง

ชื่อบุคคล โรงเรียน และเขตพื้นที่ทั้งหมดในเกมเป็นชื่อสมมติ ส่วนสถานการณ์อิงกรณีจริงที่มีแหล่งอ้างอิง (ดู `docs/scenario-bank.md` สำหรับด่าน 1–20 และ `docs/scenario-bank-2.md` สำหรับด่าน 21–30)

## ความสามารถของเกม (รุ่นปัจจุบัน)

- เมือง 3 มิติที่หมุน ซูม และเลื่อนได้ ตัวละครเดินในเมือง แตะเพื่อดูบทบาท ความพร้อม ขวัญกำลังใจ และสิ่งที่ทำไปแล้ว
- ฉากเปิดเล่าประวัติโรงเรียน (เรื่องแต่ง) ราว 10 วินาที ข้ามได้ และเปิดดูซ้ำได้จากเมนู
- ตัวละครเจ้าของเรื่องปรากฏในหน้าต่างภารกิจ ถือเอกสารและอ่านภารกิจให้ผู้เล่นฟัง
- หอเกียรติยศ 22 รางวัล แบ่งเป็นรางวัลผู้บริหาร รางวัลครูและบุคลากร และรางวัลโรงเรียน ถ้วยรางวัลจะปรากฏหน้าหอเกียรติยศในเมือง
- ปุ่มแชร์ภาพ ใช้มุมกล้องที่ผู้เล่นจัดไว้เอง (หรือเลือกมุมกว้างทั้งโรงเรียน) เลือกได้ทั้งการ์ดแนวตั้งพร้อม EXP ระดับ รางวัล ตัวชี้วัด และภาพเต็มเฟรม แชร์ผ่านเมนูของมือถือ บันทึกลงเครื่อง หรือแชร์ลิงก์ทาง Facebook และ LINE
- ทำเนียบบุคลากร แนะนำตัวละครทุกคนว่าเป็นใคร มีบทบาทอะไร แสดงหลังฉากเปิดของเกมใหม่ และเปิดดูได้จากเมนู
- เพลงประกอบและเสียงเอฟเฟกต์ที่สังเคราะห์ในเบราว์เซอร์
- งบประมาณโรงเรียนแยกจาก EXP มีเงิน 6 ประเภท ได้แก่ ค่าจัดการเรียนการสอน เงินกิจกรรมพัฒนาคุณภาพผู้เรียน เงินรายได้สถานศึกษา เงินบริจาคที่ระบุวัตถุประสงค์ งบลงทุน และเงินที่จ่ายให้นักเรียน (ใช้ซื้อของไม่ได้)
- ร้านค้าแบ่ง 5 หมวด (อาคารสถานที่ ครุภัณฑ์และสื่อ บุคลากรและการพัฒนาครู กิจกรรมนักเรียน ทุนและสวัสดิการ) ผู้เล่นต้องเลือกแหล่งเงินเอง ถ้าใช้ผิดประเภทตามหลักฐานที่ยืนยันแล้ว เงินจะถูกเรียกคืนและไม่ได้ของ ถ้ายังยืนยันตัวบทไม่ได้ เกมจะไม่ตัดสินและไม่หักเงิน รายการรถตู้ปิดไว้เพราะต้องตรวจระเบียบรถราชการก่อน
- ของที่จัดหาแล้วเห็นในเมืองทุกรายการ สิ่งก่อสร้างอยู่ถาวร ส่วนของที่ซื้อซ้ำได้ (กิจกรรม วัสดุ ทุน) ปรากฏในเมืองเฉพาะภาคเรียนที่ใช้ และบุคลากรที่จ้างเพิ่มเดินอยู่ในโรงเรียน 2 ภาคเรียน หลังจัดหา กล้องจะพาไปดูพร้อมวงแสงและป้าย "ใหม่"
- เควสระดมทรัพยากร 6 เควส เช่น ผ้าป่าการศึกษา การรับบริจาคจากบริษัท การให้เช่าลานจอดรถ ทุนเสมอภาค การยื่นคำขอตั้งงบลงทุน และการขยายพื้นที่โรงเรียนด้วยที่ดินที่ชุมชนบริจาค (ขยายได้ 2 แปลง แต่ละแปลงเพิ่มความจุ 150 คน โดมและอาคารเรียนหลังใหม่ต้องมีที่ดินแปลงแรกก่อน)
- เกณฑ์ผ่านด่านมี 2 ส่วน คือ EXP ถึงเกณฑ์ และโรงเรียนมีความพร้อมตามเกณฑ์ของด่าน (สิ่งก่อสร้างหรือของที่ต้องมี ตัวชี้วัดเก่ง ดี มีสุข สถานะการเงิน จำนวนนักเรียน หรือพื้นที่) ถ้าได้ EXP แล้วแต่โรงเรียนยังไม่พร้อม ด่านจะ "รอเกณฑ์โรงเรียน" และช่วงถัดไปยังไม่เปิด เมื่อจัดหาครบ เกมจะนับว่าผ่านให้เอง เกณฑ์ทั้งหมดอยู่ใน `js/requirements.js`
- คำถามถูกหรือผิด 76 ข้อ 3 ระดับ (พื้นฐาน ประยุกต์ เชิงลึก) ระดับที่ยากขึ้นเปิดตามจำนวนด่านที่ผ่าน คำถามมาทีละข้อห่างกันราว 2.5 นาทีขึ้นไป และจำนวนข้อที่ตอบได้ผูกกับความก้าวหน้า ข้อที่ตอบแล้วไม่กลับมาอีก ตอบถูกได้ 5,000–12,000 บาทในเกมตามระดับ ข้อระดับยาก 36 ข้อดัดแปลงจากตัวเลือกในคลังด่านที่มีแหล่งอ้างอิง
- เกมไม่บอกระดับความพร้อม R1–R4 ของบุคลากรล่วงหน้า แต่ให้ข้อสังเกตเชิงพฤติกรรมในแต่ละสถานการณ์ (`CUES` ใน `js/data/world.js`) แล้วเฉลยหลังผู้เล่นเลือกวิธีทำงาน ตัวเลือกวิธีทำงานแสดงครบ 5 แบบกับทุกคน
- การ์ดสถานการณ์กะทันหัน 13 ใบ (`js/data/cards.js`) ในรูปหนังสือพิมพ์ลอยมาจากเขต แบ่งเป็นเหตุวิกฤต 6 ใบ นโยบายด่วน 3 ใบ และการ์ดกับดักที่ควรปฏิเสธ 4 ใบ ผู้เล่นเลือกตอบรับหรือปฏิเสธ แล้วตัดสินใจต่อ 1 ขั้น เหตุวิกฤตแสดงในเมืองจริง เช่น น้ำท่วมสูงขึ้นพร้อมฝนตก ไฟดับทั้งเมือง ต้นไม้ล้มขวางประตู ฝุ่นหนา การ์ดมาทุก 1–2 ด่าน และไม่แทรกระหว่างเล่นด่าน
- ร้านค้า 44 รายการ บางรายการเปิดซื้อเมื่อผ่านด่านถึงจำนวนที่กำหนด และบางรายการช่วยลดความเสียหายจากเหตุวิกฤต (ระบบสูบน้ำ เครื่องกำเนิดไฟฟ้า ห้องปลอดฝุ่น การตัดแต่งต้นไม้)
- จำนวนนักเรียนเพิ่มหรือลดตามตัวชี้วัดและสิ่งอำนวยความสะดวก อาคารเรียนหลังใหม่เพิ่มความจุ ถ้างบใช้ได้ต่ำกว่าเกณฑ์ โรงเรียนเข้าสู่ภาวะวิกฤต นักเรียนลดลง และท้องฟ้าในเมืองหม่นลง
- เยี่ยมโรงเรียนของเพื่อนผ่านลิงก์ `?visit=รหัส` แบบอ่านอย่างเดียว ไม่ต้องมีเซิร์ฟเวอร์
- ข้อความบทนำด่านปรับเป็นภาษาเชิงวิชาการไว้ใน `js/data/copy.js` (ทับค่าใน `levels.js` ตอนโหลด)

## ขึ้น GitHub Pages ทีละขั้น (ไม่ต้องใช้คำสั่ง git)

1. สมัครหรือเข้าสู่ระบบที่ github.com
2. กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository**
3. ตั้งชื่อ repository เช่น `ban-suan-leader` เลือก **Public** แล้วกด **Create repository**
   - GitHub Pages แบบฟรีต้องใช้ repository สาธารณะ ถ้าใช้บัญชีที่มี GitHub Pro จะตั้งเป็น Private ก็ได้
4. ในหน้า repository ใหม่ กดลิงก์ **uploading an existing file**
5. แตกไฟล์ zip ของเกม แล้วลาก **ไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างในโฟลเดอร์ `game`** ลงไป
   - `index.html` ต้องอยู่ชั้นนอกสุดของ repository ไม่ใช่อยู่ใน `game/index.html`
   - ไฟล์ `.nojekyll` เป็นไฟล์ซ่อน บางเครื่องจะไม่เห็นตอนลาก ถ้าไม่ได้อัปโหลดไปเกมก็ยังทำงานได้
6. เลื่อนลงไปกด **Commit changes**
7. ไปที่แท็บ **Settings** แล้วเลือก **Pages** ที่เมนูด้านซ้าย
8. ตรง **Build and deployment** ให้ Source เป็น **Deploy from a branch** เลือก Branch **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
9. รอราว 1–3 นาที แล้วรีเฟรชหน้า Pages จะเห็นลิงก์ในรูป `https://ชื่อผู้ใช้.github.io/ban-suan-leader/`

ถ้าเปิดลิงก์แล้วหน้าว่าง ให้ตรวจว่า `index.html` อยู่ชั้นนอกสุด และชื่อโฟลเดอร์ `js`, `css`, `vendor` สะกดเป็นตัวพิมพ์เล็กตรงตามเดิม (GitHub แยกตัวพิมพ์เล็กกับใหญ่)

### ถ้าใช้คำสั่ง git

```bash
cd game
git init
git add .
git commit -m "เกมเส้นทางผู้บริหาร เมืองบ้านสวน"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/ban-suan-leader.git
git push -u origin main
```

จากนั้นตั้งค่า Pages ตามข้อ 7–9

## ทดลองเปิดในเครื่องก่อนอัปโหลด

เกมใช้ JavaScript module จึงเปิดด้วยการดับเบิลคลิก `index.html` ตรง ๆ ไม่ได้ ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เช่น

```bash
cd game
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## การบันทึกความคืบหน้า

- เกมบันทึกอัตโนมัติใน `localStorage` ของเบราว์เซอร์ทุกครั้งที่ผู้เล่นตัดสินใจ ไม่มีข้อมูลถูกส่งออกจากเครื่อง
- ข้อมูลผูกกับเบราว์เซอร์และโดเมน ถ้าเปลี่ยนเครื่อง ล้างข้อมูลเบราว์เซอร์ หรือเปิดโหมดไม่ระบุตัวตน ความคืบหน้าจะไม่ตามไป
- เมนู **บันทึก** ในเกมให้ **รหัสสำรอง** (ขึ้นต้นด้วย `BSV1.`) และไฟล์ `.json` ผู้เล่นนำไปวางในอีกเครื่องเพื่อเล่นต่อได้
- ถ้าใช้ในห้องอบรม แนะนำให้ผู้เรียนคัดลอกรหัสสำรองเก็บไว้ทุกครั้งที่จบช่วง

## แก้เนื้อหาด่าน

มี 2 ทาง

1. แก้ใน `docs/scenario-bank.md` ตามรูปแบบตารางเดิม (ตัวเลือก | ชั้น 1 | ป้าย | EXP | เฉลย) แล้วรัน

   ```bash
   python3 tools/parse_levels.py docs/scenario-bank.md js/data/levels.js
   ```

   สคริปต์จะตรวจว่าทุกขั้นมี 5 ตัวเลือก และมีตัวเลือกผิดระเบียบไม่เกิน 1 ข้อ
2. แก้ใน `js/data/levels.js` โดยตรง เหมาะกับการแก้คำผิดเล็กน้อย

ค่า `legal` ของตัวเลือกมี 3 ค่า คือ `ok`, `illegal` และ `undetermined` (ยังยืนยันไม่ได้ ไม่นับคะแนนชั้นที่ 1)

## ข้อควรรู้ก่อนใช้จริง

- ด่าน 21–30 (ช่วงที่ 5 วางระบบระยะยาว และช่วงที่ 6 ตรวจสอบภายนอกและความรับผิด) ใช้แหล่งอ้างอิงที่เป็นข่าว บทความ และเอกสารเผยแพร่ของเขตพื้นที่เป็นส่วนใหญ่ ตัวเลือกที่น่าจะขัดกฎหมายแต่ยังไม่ได้เปิดตัวบทใช้ค่า "ไม่ตัดสิน" (ไม่นับคะแนนชั้นที่ 1) จุดที่ต้องตรวจซ้ำ ได้แก่ เลขข้อค่าปรับและการงดค่าปรับในระเบียบพัสดุ (ด่าน 22) หน้าที่ผู้บังคับบัญชาตาม ว 9/2564 และมาตรา 98 (ด่าน 23) กฎหมายแรงงานต่างด้าวฉบับปัจจุบันและหนังสืออนุญาตชั่วคราวของคุรุสภา (ด่าน 24) ตัวบทมาตรา 8 ของกฎหมายความรับผิดทางละเมิด (ด่าน 26) เลขมาตราการละทิ้งหน้าที่และระเบียบการลา (ด่าน 27) กฎหมายการตั้งครรภ์ในวัยรุ่น (ด่าน 28) ชื่อกฎหมายควบคุมยาสูบที่ใช้บังคับ (ด่าน 29) และขั้นตอนอุทธรณ์การจัดซื้อจัดจ้าง (ด่าน 30)

- ตัวเลขเงินในเกมเป็น "บาทในเกม" ที่กำหนดเพื่อการเล่น ไม่ใช่อัตราเงินอุดหนุนจริง ส่วนการตัดสินแหล่งเงินอิงหลักฐานใน `docs/scenario-bank.md` และบันทึกวิจัย รายการที่ยังยืนยันไม่ได้มีระบุไว้ในหน้าซื้อทุกครั้ง

- ข้อมูลระเบียบเป็นสถานะ ณ ตุลาคม 2569 ส่วนที่ 7 ของ `docs/scenario-bank.md` มี 24 รายการที่ต้องตรวจกับตัวบทต้นฉบับ รายการที่มีเครื่องหมาย * จะเปลี่ยนผลถูก/ผิดถ้าตัวบทต่างไป
- ป้ายสไตล์ในคลังยังไม่สมดุล ป้าย "บริหารตามระบบและระเบียบ" เป็นป้ายหลักของ 131 ตัวเลือก ขณะที่ป้ายมุ่งการเรียนการสอนมี 18 และนวัตกรรมมี 11 เกมจึงคิดคะแนนเป็นสัดส่วนของโอกาสที่ได้เลือก แต่ถ้าจะใช้ผลโปรไฟล์จริงจัง ควรเพิ่มป้ายวิชาการ พัฒนาครู และนวัตกรรมให้ได้ป้ายละราว 30 ครั้ง
- ค่า EXP ป้ายสไตล์ และเกณฑ์ตัดโปรไฟล์มาจากดุลยพินิจผู้ออกแบบ ยังไม่ผ่านการตรวจ IOC หรือทดลองนำร่อง ผลโปรไฟล์จึงใช้เพื่อสะท้อนคิดเท่านั้น ไม่ใช่เครื่องมือวินิจฉัยหรือคัดเลือก
- ข้อคำถามทั้งหมดเขียนขึ้นใหม่จากกรณีไทย ไม่ได้แปลหรือดัดแปลงจากแบบสอบถาม MLQ
- การ์ดสถานการณ์กะทันหันส่วนใหญ่ตัดสินจากหลักความปลอดภัยและธรรมาภิบาลทั่วไป มีเพียงบางใบที่มีแหล่งอ้างอิง และเป็นข่าว (แหล่งรอง) เช่น อำนาจผู้อำนวยการสั่งปิดเรียนกรณีพิเศษ 7 วัน (ข่าวปี 2563) แนวปฏิบัติเรื่องฝุ่น (ข่าวปี 2567) และแนวทาง กกต. เรื่องความเป็นกลางทางการเมือง
- คำถามถูกหรือผิดชุดเดิม 17 จาก 40 ข้ออ้างแหล่งรอง (ข่าว เว็บไซต์เขตพื้นที่ บทความ) เกมระบุ "แหล่งรอง" ไว้ท้ายคำอธิบาย ควรตรวจกับตัวบทก่อนใช้สอน
- เควสขยายพื้นที่โรงเรียนตัดสินจากหลักความโปร่งใสและทรัพย์สินของทางราชการ ยังไม่ได้อ้างมาตราของกฎหมายที่ราชพัสดุหรือระเบียบรับบริจาค เพราะยังตรวจตัวบทไม่ครบ
- เกณฑ์ความพร้อมประจำด่านกำหนดเพื่อการเล่น ไม่ใช่เกณฑ์ทางราชการ
- ด่าน 17 และ 19 มีคำเตือนเนื้อหาและให้ข้ามได้ (ข้ามได้แม้โรงเรียนยังไม่ผ่านเกณฑ์ความพร้อม) ก่อนใช้กับผู้เรียนควรให้ผู้เชี่ยวชาญด้านคุ้มครองเด็กอ่านสองด่านนี้
- ฟอนต์ Mitr และ Sarabun โหลดจาก Google Fonts ถ้าเครื่องออฟไลน์ เกมจะใช้ฟอนต์ไทยของระบบแทน
