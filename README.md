# เส้นทางผู้บริหาร: เมืองบ้านสวน

เกมเตรียมความพร้อมผู้บริหารสถานศึกษามัธยมศึกษาไทย 20 ด่าน ผู้เล่นรับบทผู้อำนวยการ "โรงเรียนบ้านสวนวิทยา" ในเมือง 3 มิติที่หมุน ซูม และเลื่อนดูได้ แตะตัวละครเพื่อดูสิ่งที่เขาทำไปแล้ว และเลือกวิธีทำงานกับเขาได้ 5 แบบ ได้แก่ สั่งการ สอนงาน สนับสนุน มอบหมาย และปรึกษาหารือ เนื้อหาครอบคลุมงาน 4 ด้านตามกฎกระทรวงกระจายอำนาจฯ พ.ศ. 2550 ด้านละ 5 ด่าน

ชื่อบุคคล โรงเรียน และเขตพื้นที่ทั้งหมดในเกมเป็นชื่อสมมติ ส่วนสถานการณ์อิงกรณีจริงที่มีแหล่งอ้างอิง (ดู `docs/scenario-bank.md`)

## ความสามารถของเกม (รุ่นปัจจุบัน)

- เมือง 3 มิติที่หมุน ซูม และเลื่อนได้ ตัวละครเดินในเมือง แตะเพื่อดูบทบาท ความพร้อม ขวัญกำลังใจ และสิ่งที่ทำไปแล้ว
- ฉากเปิดเล่าประวัติโรงเรียน (เรื่องแต่ง) ราว 10 วินาที ข้ามได้ และเปิดดูซ้ำได้จากเมนู
- ตัวละครเจ้าของเรื่องปรากฏในหน้าต่างภารกิจ ถือเอกสารและอ่านภารกิจให้ผู้เล่นฟัง
- หอเกียรติยศ 18 รางวัล แบ่งเป็นรางวัลผู้บริหาร รางวัลครูและบุคลากร และรางวัลโรงเรียน ถ้วยรางวัลจะปรากฏหน้าหอเกียรติยศในเมือง
- ปุ่มแชร์ภาพ สร้างภาพขนาด 1080×1350 พร้อม EXP ระดับ รางวัล และตัวชี้วัด แชร์ผ่านเมนูของมือถือ บันทึกลงเครื่อง หรือแชร์ลิงก์ทาง Facebook และ LINE
- เพลงประกอบและเสียงเอฟเฟกต์ที่สังเคราะห์ในเบราว์เซอร์
- ข้อความบทนำด่านปรับเป็นภาษาเชิงวิชาการไว้ใน `js/data/copy.js` (ทับค่าใน `levels.js` ตอนโหลด)

## ขึ้น GitHub Pages ทีละขั้น (ไม่ต้องใช้คำสั่ง git)

1. สมัครหรือเข้าสู่ระบบที่ github.com
2. กดปุ่ม **+** มุมขวาบน แล้วเลือก **New repository**
3. ตั้งชื่อ repository เช่น `ban-suan-leader` เลือก **Public** แล้วกด **Create repository**
   - GitHub Pages แบบฟรีต้องใช้ repository สาธารณะ ถ้าใช้บัญชีที่มี GitHub Pro จะตั้งเป็น Private ก็ได้
4. ในหน้า repository ใหม่ กดลิงก์ **uploading an existing file**
5. แตกไฟล์ zip ของเกม แล้วลาก **ไฟล์และโฟลเดอร์ทั้งหมดที่อยู่ข้างในโฟลเดอร์ `game`** ลงไป
   - `index.html` ต้องอยู่ชั้นนอกสุดของ repository ไม่ใช่อยู่ใน `game/index.html`
   - ไฟล์ `.nojekyll` เป็นไฟล์ซ่อน บางเครื่องจะไม่เห็นตอนลาก ถ้าไม่ได้อัปโหลดไปเกมก็ยังทำงานได้
6. เลื่อนลงไปกด **Commit changes**
7. ไปที่แท็บ **Settings** แล้วเลือก **Pages** ที่เมนูด้านซ้าย
8. ตรง **Build and deployment** ให้ Source เป็น **Deploy from a branch** เลือก Branch **main** และโฟลเดอร์ **/ (root)** แล้วกด **Save**
9. รอราว 1–3 นาที แล้วรีเฟรชหน้า Pages จะเห็นลิงก์ในรูป `https://ชื่อผู้ใช้.github.io/ban-suan-leader/`

ถ้าเปิดลิงก์แล้วหน้าว่าง ให้ตรวจว่า `index.html` อยู่ชั้นนอกสุด และชื่อโฟลเดอร์ `js`, `css`, `vendor` สะกดเป็นตัวพิมพ์เล็กตรงตามเดิม (GitHub แยกตัวพิมพ์เล็กกับใหญ่)

### ถ้าใช้คำสั่ง git

```bash
cd game
git init
git add .
git commit -m "เกมเส้นทางผู้บริหาร เมืองบ้านสวน"
git branch -M main
git remote add origin https://github.com/<ชื่อผู้ใช้>/ban-suan-leader.git
git push -u origin main
```

จากนั้นตั้งค่า Pages ตามข้อ 7–9

## ทดลองเปิดในเครื่องก่อนอัปโหลด

เกมใช้ JavaScript module จึงเปิดด้วยการดับเบิลคลิก `index.html` ตรง ๆ ไม่ได้ ต้องเปิดผ่านเว็บเซิร์ฟเวอร์ เช่น

```bash
cd game
python3 -m http.server 8000
```

แล้วเปิด `http://localhost:8000`

## การบันทึกความคืบหน้า

- เกมบันทึกอัตโนมัติใน `localStorage` ของเบราว์เซอร์ทุกครั้งที่ผู้เล่นตัดสินใจ ไม่มีข้อมูลถูกส่งออกจากเครื่อง
- ข้อมูลผูกกับเบราว์เซอร์และโดเมน ถ้าเปลี่ยนเครื่อง ล้างข้อมูลเบราว์เซอร์ หรือเปิดโหมดไม่ระบุตัวตน ความคืบหน้าจะไม่ตามไป
- เมนู **บันทึก** ในเกมให้ **รหัสสำรอง** (ขึ้นต้นด้วย `BSV1.`) และไฟล์ `.json` ผู้เล่นนำไปวางในอีกเครื่องเพื่อเล่นต่อได้
- ถ้าใช้ในห้องอบรม แนะนำให้ผู้เรียนคัดลอกรหัสสำรองเก็บไว้ทุกครั้งที่จบช่วง

## แก้เนื้อหาด่าน

มี 2 ทาง

1. แก้ใน `docs/scenario-bank.md` ตามรูปแบบตารางเดิม (ตัวเลือก | ชั้น 1 | ป้าย | EXP | เฉลย) แล้วรัน

   ```bash
   python3 tools/parse_levels.py docs/scenario-bank.md js/data/levels.js
   ```

   สคริปต์จะตรวจว่าทุกขั้นมี 5 ตัวเลือก และมีตัวเลือกผิดระเบียบไม่เกิน 1 ข้อ
2. แก้ใน `js/data/levels.js` โดยตรง เหมาะกับการแก้คำผิดเล็กน้อย

ค่า `legal` ของตัวเลือกมี 3 ค่า คือ `ok`, `illegal` และ `undetermined` (ยังยืนยันไม่ได้ ไม่นับคะแนนชั้นที่ 1)

## ข้อควรรู้ก่อนใช้จริง

- ข้อมูลระเบียบเป็นสถานะ ณ ตุลาคม 2569 ส่วนที่ 7 ของ `docs/scenario-bank.md` มี 24 รายการที่ต้องตรวจกับตัวบทต้นฉบับ รายการที่มีเครื่องหมาย * จะเปลี่ยนผลถูก/ผิดถ้าตัวบทต่างไป
- ป้ายสไตล์ในคลังยังไม่สมดุล ป้าย "บริหารตามระบบและระเบียบ" เป็นป้ายหลักของ 131 ตัวเลือก ขณะที่ป้ายมุ่งการเรียนการสอนมี 18 และนวัตกรรมมี 11 เกมจึงคิดคะแนนเป็นสัดส่วนของโอกาสที่ได้เลือก แต่ถ้าจะใช้ผลโปรไฟล์จริงจัง ควรเพิ่มป้ายวิชาการ พัฒนาครู และนวัตกรรมให้ได้ป้ายละราว 30 ครั้ง
- ค่า EXP ป้ายสไตล์ และเกณฑ์ตัดโปรไฟล์มาจากดุลยพินิจผู้ออกแบบ ยังไม่ผ่านการตรวจ IOC หรือทดลองนำร่อง ผลโปรไฟล์จึงใช้เพื่อสะท้อนคิดเท่านั้น ไม่ใช่เครื่องมือวินิจฉัยหรือคัดเลือก
- ข้อคำถามทั้งหมดเขียนขึ้นใหม่จากกรณีไทย ไม่ได้แปลหรือดัดแปลงจากแบบสอบถาม MLQ
- ด่าน 17 และ 19 มีคำเตือนเนื้อหาและให้ข้ามได้ ก่อนใช้กับผู้เรียนควรให้ผู้เชี่ยวชาญด้านคุ้มครองเด็กอ่านสองด่านนี้
- ฟอนต์ Mitr และ Sarabun โหลดจาก Google Fonts ถ้าเครื่องออฟไลน์ เกมจะใช้ฟอนต์ไทยของระบบแทน
